# D.O.P.A. - G.A.K.I. オンライン記録のセットアップ

記録サーバーは「Googleスプレッドシート＋Apps Script（GAS）」、ゲームの置き場所は「GitHub Pages」です。所要時間は合わせて10〜15分です。

## 1. 記録サーバー（スプレッドシート＋GAS）

1. Googleドライブで **新規 → Googleスプレッドシート** を作り、名前を「DOPA-GAKI 記録」にする
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `function myFunction() {}` を全部消して、**Code.gs の中身を全部貼り付け** → 💾保存
4. 右上の **デプロイ → 新しいデプロイ**
   - 歯車（種類の選択）→ **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - **デプロイ** を押す
5. 「アクセスを承認」→ 自分のGoogleアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら **詳細 → （安全ではないページ）に移動 → 許可**
   - 自分で作ったスクリプトなので問題ありません。このスクリプトが触れるのは、このスプレッドシートだけです
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピーして、Claude に送る

> 初めて記録が届いた時に、スプレッドシートに「Players」（コールサイン）と「Plays」（1回ごとの結果）のシートが自動でできます。
> コードを直した時は **デプロイ → デプロイを管理 → ✏️編集 → バージョン: 新バージョン → デプロイ**（URLが変わりません）。「新しいデプロイ」にするとURLが変わるので注意。

## 2. ゲームの置き場所（GitHub）

Claude からは新しいリポジトリを作れないので、ここだけお願いします。

1. https://github.com/new を開く
2. Repository name: **dopa-gaki**、**Public**、「Add a README file」に✓ → **Create repository**
3. Claude に「作った」と伝える → Claude がゲームを置いて GitHub Pages を有効にします
4. 公開先: **https://yukito0240.github.io/dopa-gaki/**

## 3. 試験の始め方

- 上のアドレスを試験の参加者に送る（claude.ai のアカウントは不要）
- 初めて開くと「コールサイン」を決める画面が出ます（同じ名前は早い者勝ち・この端末にずっと残る・変更は1回まで）
- 部屋は最初「本部」。記録 → 部屋 → 合言葉を入れると別の部屋に移れます
- スマホのホーム画面に追加すると、アイコン付きでアプリのように開けます（Safari の共有 → ホーム画面に追加）

## 注意

- 設定（リロード時間・制限時間など）を変えて遊んだ回は、ランキングに送りません
- 記録はスプレッドシートにそのまま残るので、不正な記録は行を消せば消えます
- claude.ai のアーティファクト版はこれまで通り遊べますが、オンライン記録は出ません（claude.ai の中からは外のサーバーに送れないため）
