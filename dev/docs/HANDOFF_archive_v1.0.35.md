## 3Dモデルの作り方（v0.9.0）
- 元: ユーザーがMixamoから落としたFBX（本体は With Skin、動きは Without Skin）。骨の名前が同じなので別キャラの動きも流用できる
- 変換: ヘッドレスChromeで FBXLoader→GLTFExporter（模様は jpeg/png、1024px）→ gltf-transform（/home/claude/tools）で weld→simplify→resize→webp→resample→meshopt
- 元のFBXと変換スクリプトは作業環境にしかない（消える）。soldier は index.html に埋め込み済み。ゾンビ4体は公開ページの assets/*.glb.txt にある（Artifact の read で path を指定すれば取り出せる）。ナレッジは容量が足りず置けない。ユーザーにも .glb を渡してある
- 本体の向きは +z、縮尺は cm（CFG.model.scale=0.01）

## 注意
- このセッションの GitHub は新しいリポジトリを作れない（user/repos は403）。ユーザーに作ってもらい add_repo(push) で付ける
- テストの中で await すると、前のテストの setTimeout（タイトル背景の切替など）が走って G.stage が変わる。待つテストは G.stage / G.state を戻す
- 何度も呼ばれる関数（buildSettings など）の中で addEventListener しない。上書きの on〜 を使うか、起動時に1回だけ登録する（v1.0.29）
- 「読み込みを待ってもう一度呼ぶ」処理は、読めなかった時に無限に呼び続けないよう、待った後に有無を確かめる（v1.0.28 Sound.sel）
- 撮影スクリプトで pkill -f <名前> を使うと、同じ名前を含む自分のシェルまで止まる
- 「援軍の爆撃は群れの塊を…撃ち漏らしが少なく」のテストは乱数でまれに落ちる（残り3/40など）。もう一度回すと通る
- ユーザーは音をスマホで聞いて選んでいる。「聞こえない」は音量の話。帯域の理屈で音色を変えに行かない（v1.0.26）
- 埋め込み音を Sound.trim に通すと頭の無音が削られて位置がずれる。ループ位置を持つ音（menu）や落下音は trim しない（v1.0.22）
- 粒子（Points）を「サイズ0」で消しても、GPUは点を最小1ピクセルで描く。消した粒は画面外へ出す（v1.0.21）。CPU側の数を数える検査では見つからないので、撮影して比べること
- 行の途中の `// コメント` が処理を飲み込む不具合は何度も再発した（v0.8.4・v0.9.8・v1.0.4、さらに v0.7.6 の艦の傾きと v1.0.4 の finaleView が気づかれずに残っていた）。v1.0.5 から run_test.mjs が静的検査で落とす。行の途中のコメントは必ず `/* */`
- スローモーション中に「毎フレーム確率」で出す演出は、スロー倍率ぶん密に・長く残る。粒子の発生は dt に比例させる（v1.0.20 のチリ）
- ヘッドレスの撮影は本番モード（?test=1 なし）だと描画が重く、1本のスクリプトで2ステージ以上撮ると時間切れになりやすい。1ステージずつ撮る。?test=1 は起動時に自己テストが走るので撮影には使わない（addInitScript で bt_brief_v1 を入れてブリーフィングを飛ばす）
