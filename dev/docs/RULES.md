# RULES — 開発規約（短く守る）
最終更新: 2026-11-01

## 進め方
- 読む順: HANDOFF → RULES → FUNCTIONS。正本（GitHub の dev/index.html）は触る関数だけ読む
- 着手前に「触る関数名＋方針3行」を宣言して承認を待つ。見た目は写真、音は試聴で確認してから入れる
- 修正は関数単位で置換（全体書き換え禁止）
- 検証は `node tests/run_test.mjs` の出力をそのまま貼る。記録サーバーを触ったら `node server/gas_test.mjs` も
- 宣言外の変更、関数数/テスト数の減少は未完了扱い
- 同じ修正に2回失敗したら止めて引き継ぐ。残量30%前に HANDOFF 更新

## コード
- 4スペース、不要な空行なし、コメントは一行で簡潔。行の途中のコメントは `/* */`
- 関数の直前に一行説明（`// 名前: 役割`）
- 変更箇所に `// vX.Y.Z: 変更理由` を付け、ファイル冒頭の履歴を更新
- 数値は CFG/WEAPONS 定数に集約（関数内ハードコード禁止）
- 新しい関数・変数を作る前に FUNCTIONS.md で既存を確認（重複禁止）
- 新機能には runTests の自己テストを1つ以上
