# SPEC — Project: BREAKTHROUGH（仮） 正本仕様
最終更新: 2026-10-26 / v1.0.9（襲来の再生・視点切替・決め手・開始演出・弾の炎・レール）

## 1. コンセプト
- 『Dust Front』（RTS）の見た目と重い音を、**スマホで隙間時間に遊べる1タップ砲撃ゲーム**に落とし込む
- 「敵工兵が補強し続ける要塞を、2分以内に砲撃で粉砕する」ストレス発散ゲーム
- 敵の反撃はなし（壊すだけ）。1回2分

## 2. 見た目・音の基準
- 正本は REFERENCE_VIDEO.md（参考動画の実測値）
- 見た目: 曇天の明るい灰色の地面（#6a656e系）、赤く光る結晶の群生、六角形のコンクリート台座、暗い鋼の車両に赤い灯火、白灰の砲煙・砂塵
- 見た目の作り方: **3D＋ドット絵風フィルター**（低解像度で描いて最近傍拡大、奥行き差の黒い輪郭線、色数削減＋4x4ディザ）。初期は1ドット=1 CSSピクセル（設定で なし/細かい/粗い）
- 構造物は作り込む: 司令部（パネル目地・鉄筋・換気口・ハッチ・屋上の対空機関砲）、外壁（ジャージー障壁2段＋土嚢）、鉄骨格子の電波塔（赤/灰の帯）、コンテナ、燃料タンク（誘爆）、レーダー
- 音: **ユーザー提供の効果音（7素材に加工してHTML末尾に埋め込み）を主に使い**、音程・長さ・こもりを毎回変える。着弾は「爆破音」（blast＋debris＋重低音）。合成はノイズのみ（v0.4.0で合成のサブ低音＝「ぽん」を撤去）。着弾音は着弾の瞬間に鳴らす（音速の遅れは最大0.05秒、素材の先頭無音は除去）
  - boom=155mm発射 / cannon=203mm発射 / gun=40mm / blast・heavy・debris=着弾・倒壊 / amb=遠い戦場の環境音
- 爆弾は落ちながら笛の音（試聴で選んだ H_4600_side35 の音源をそのまま。1回の爆撃に1回、鳴り終わりが最初の着弾に重なる。v0.7.6）、ミサイルは突入前に「ゴォォ」が高く大きくなる。空爆は着弾を短く重ねて最後に長い地鳴り、VLSはこだまと深い地鳴り（v0.7.2〜0.7.3）
- **電子音（矩形波・鋸波・三角波、UIの「ピッ」）は一切使わない**。装填・切替は機械音（ガチャン）

## 3. ルール
- 勝利: 2分以内に全目標を破壊（司令部コア＝HP0のみ、電波塔2基＝頂部アンテナがHP0／3m以上落下／大きく傾く）
- 燃料タンクは壊すと誘爆し、周囲を巻き込む
- 司令部コアは床に固定（吹き飛ばない）。目標の上に名前とHPバーのマーカーを表示。画面外の目標は画面の端に黄色枠＋矢印で示す（v0.7.1、全ステージ）
- 敗北: 時間切れ
- 敵は目標そのものは再建できない（壁・装甲・土嚢のみ）

### 空軍基地（v0.6.0）
- 配置: 奥に格納庫3棟（かまぼこ形）・管制塔・レーダー、中央に横向きの滑走路（左→右へ離陸）と誘導路・エプロン、手前に燃料タンクと弾薬コンテナ、柵。砲兵は丘の上
- 敵機: 戦闘機5・輸送機1が駐機。開始6秒後から15秒ごとに1機が誘導路→停止線→滑走→離陸→上空を16秒旋回→奥へ逃走
- 得点: 地上（駐機・誘導中・滑走中）で壊すと1000点、離陸後の撃墜は1500点、逃げられたら0点。機体は爆発して近くの機体を巻き込む
- 滑走路: 穴があると離陸できず停止線で待つ。滑走中に穴へ達すると大破（地上撃破）。敵工兵が穴を埋めに来る
- 対空: 弾は飛行中の敵機の近く（2.5m）で炸裂する（近接信管）。飛行中の機体をタップすると旋回まで見越して撃つ
- 勝利: 管制塔とレーダーを壊し、全機を処理（撃破・撃墜・逃走）
- v0.6.1: 規模拡大（滑走路168m・格納庫5棟・戦闘機6＋輸送機2、13秒ごとに出発）、砲兵はさらに後ろ。滑走区間に残骸があると離陸せず、工兵が撤去する（滑走中に残骸へ達すると大破）

### 海軍基地（v0.7.0）
- 配置: 手前から 丘の砲兵 → 岸壁（司令部・沿岸レーダー＝手前の中ほど、クレーン3基・乾ドック・燃料タンク・弾薬庫・倉庫）→ 港内（桟橋3本）→ 防波堤（右奥に港口、両端に灯台）→ 外洋
- 艦: 駆逐艦2・フリゲート2・輸送船1・潜水艦1。桟橋ごとに2隻を横付け（内側＝桟橋側）。8秒後から13秒ごとに外側から出航し、水路→港口→外洋の奥へ逃げる（v0.7.1: 4〜6m/秒、港口まで約20〜35秒）
- 外側の艦が桟橋で沈むと内側の艦は出られない（沈めないと勝てない）
- 潜水艦は港口を出て3秒で潜航し、当たらなくなる
- 撃沈: 傾いて沈む。40%で誘爆して船体が真ん中で折れ、大爆発で横の艦も傷める。港内1200点・港外1800点
- 弾は船体に当たり、海に落ちた弾は海面で水柱。停泊・航行中の艦をタップすると艦を狙う（航行中は見越し）
- v0.7.6: 艦は艦首が航路をなぞり、艦尾は艦首に引かれて艦の軸方向にだけ動く（艦尾が外へ滑らない）。自陣は岸壁から約14m遠い
- v0.7.5: 港は元の大きさ。港内は2.5m/秒でゆっくり曲がり（円弧）、港口を出たら巡航速度までゆっくり加速して一定。白波は船首波の泡・砕けて途切れるV字（約19.5°）・艦の幅の艦尾の泡・スプレーレールの飛沫
- （旧v0.7.4）艦は艦尾が桟橋を抜けるまで直進→港口へ斜め→港口で南へ（半径40mの円弧）。ゆっくり加速して巡航速度で一定。白波は艦首のV字と艦尾の泡の帯
- （旧）艦は角を丸めた航路（半径18m）を進み、曲がるときは減速して外側へ傾く。艦首・艦尾に航跡（v0.7.2）
- 工兵は岸壁の施設（クレーン・乾ドック・燃料タンク・弾薬庫・倉庫）を再建

### 市街地の工兵（v0.6.1）
- 河川敷公園の資材置き場から工兵（設定の2/3人）が出て、壊れたビルの階・家・倉庫・橋を下から順に再建する。地面の高さに沿って歩き、川は橋、崖は坂道を通る
- 破壊率は再建されると戻る。勝利は75%
- 工兵は無事な橋だけを渡る。2本とも落ちていたら川の南は後回しにして、北岸から橋を先に直す。渡る途中で橋が落ちたら止まる（v0.7.2）
- 橋は壊せる。橋脚を壊すと橋桁が川へ落ちる
- 手前の建物に阻まれる低い弾道は、装薬を減らした中くらいの弾道に切り替わる。それでも無理なら真上からの曲射（市街地・空軍基地・海軍基地。v0.7.1）
- v0.5.2: 砲兵は丘の縁の直前に並び、崖の上から撃ち下ろす。低い弾道が地形に阻まれるときは自動で曲射になる
- 地形の高低差は Rapier の heightfield。格子線がちょうど整数座標に乗るとレイを取りこぼすため、格子を少しずらしている

## 4. 操作（スマホ縦が主、PCも可）
- タップした地点へ選択中の兵装で砲撃（砲塔が向いて0.12秒後に発射）。40mmは長押しで連射（指を動かすと照準が追従）
- 画面下のボタン（5列×2段：9兵装＋FEVER）で兵装切替（装填ゲージ・残り回数・残弾つき）
- 長押し連射（40mm・76mm）中は、狙いの照準（敵機・敵艦ならロック枠と見越し点）と、指の上に拡大の吹き出しを表示（v0.7.2）
- 長押し連射（40mm・76mm）は指を0.15秒止めてから始まる。それより早く横に動かすと視点移動、短いタップは短連射（v0.6.1）
- 連鎖コンボ: 1.2秒以内に壊し続けるとコンボが続き、1つごとに加点（2×(n-1)点）。5連以上で「×n COMBO」を表示。10・25・50連と、燃料タンク・VLS・艦の誘爆では0.6秒だけスロー（v0.7.4）
- フィーバー: 破壊・撃破でゲージが溜まり、満タンでFEVERを押すと8秒間 装填ほぼゼロ・速射が速い
- 横ドラッグで視点を左右に移動、ピンチ（PCはホイール）でズーム
- PC: クリック=タップ、1〜9=兵装、F=フィーバー、M=消音、R=再出撃

## 6. 敵AIと工兵
- AI（ユーティリティAI・完全ローカル）は資源を貯め、修理／再建／増設の候補を採点して**作業依頼**を出す
- 依頼は**工兵**が実行する: 兵舎から歩いて現場へ → 工具を振る（火花・打撃音・足場が伸びる）→ 完成
- 手の空いた工兵がいなければAIは依頼を出さない。工兵は爆風で吹き飛ぶ（撃破数を表示）
- 工兵は6人で開始、兵舎から2.5秒ごとに補充（最大10人）。作業中に倒れても足場と進捗は残り、別の工兵が引き継ぐ
- v0.4.0: 目標は回復しないが、壁・司令部・コンテナ・燃料タンク・レーダーなど周りの建物は元の形で再建される。作業時間は約半分、指示間隔0.35秒
- 狙いどころ: 「壁を壊す」か「工兵を減らして補強を止める」か

## 要塞（v0.8.0 作り直し・ADR-001）
- 手前から: 対戦車障害物の列 → 塹壕と土嚢（正門の前は通路）→ 六角形の対空トーチカ2基 → 四角い外壁（前は2段で上段は胸壁、四隅に見張り塔、中央に鉄扉の正門）
- 壁の内側: 司令部（3階・六角の台座・床に固定したコア）、左に燃料タンク3基と配管（司令部へ・弾薬庫へ）、左奥に弾薬庫、右に発電所、右奥に通信塔、手前にコンテナ置き場、奥にレーダーと兵舎
- 壁の外の奥: 敵の大型砲（六角の台座に固定・砲身3本）。前に障壁の弧
- 目標は司令部コアと敵大型砲の2つ
- 敵の大型砲: 9秒後から15秒ごとに撃ち返す。2.5秒前に「砲撃準備」と表示し砲身が赤く明滅 → 発射（反動・白煙・発射音）→ 落下の笛 → 自陣の手前（16〜32m）に着弾して爆発と揺れ。自陣は壊れない。壊すと大爆発でスロー
- 対空トーチカ: 1.8秒撃って2.4秒止まるを繰り返し、黄色い曳光弾で空を掃く。爆撃機が来ると見越して狙う（見た目だけ）
- 誘爆: 弾薬庫は大爆発＋連続爆発。配管は燃えて隣の配管・タンク・弾薬庫へ火が伝わる
- 工兵: 外壁は内側から直す。壁の内外は正門を通り、裏（大型砲）へは壁の外を回る
