# D.O.P.A. - G.A.K.I.

**Devastating Overmatch Power Against Generating Artificial Killing Intelligence**
（対生成型殺傷人工知能超絶破壊的圧倒火力）

AIが補強し続ける要塞を重火器で粉砕する、スマホ縦持ちの3D破壊ゲーム（単一HTML／Three.js・Rapier・Web Audio）。

- 遊ぶ: https://yukito0240.github.io/dopa-gaki/
- オンライン記録: Google Apps Script＋スプレッドシート（`server/Code.gs`、手順は `server/SETUP.md`）
- `index.html` は開発用の正本から `tools/build_pages.py` で書き出したものです
